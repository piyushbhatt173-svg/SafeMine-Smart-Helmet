# 🪖 SafeMine Smart Helmet

An AI-powered IoT-based smart helmet designed to improve worker safety in hazardous environments such as mines and industrial workplaces.

## 🚀 Features

- 🌡️ Real-time temperature and humidity monitoring
- 🛢️ Gas detection for hazardous gases
- 📈 Pressure monitoring
- 🧭 Motion and impact detection
- 🚨 Instant safety alerts
- 📡 ESP32-based IoT connectivity
- ☁️ Firebase-based real-time monitoring
- 📊 Worker safety dashboard

## 🔧 Hardware

- ESP32
- DHT11
- MQ2 Gas Sensor
- BMP180
- MPU6050
- Buzzer

## 💻 Technologies

- C/C++
- ESP32
- IoT
- Firebase
- HTML
- CSS
- JavaScript

## 🎯 Objective

SafeMine aims to provide real-time monitoring and early warning for hazardous conditions, helping improve worker safety and emergency response.

## 🏆 Achievement

Developed as a National Level Hackathon project and selected among the top teams.

## 👥 Team

SafeMine was developed as a collaborative hackathon project.
